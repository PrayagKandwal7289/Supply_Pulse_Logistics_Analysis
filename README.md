# Supply Pulse Logistics | SQL + Power BI Analytics Project

## Project Overview
Developed an end-to-end Supply Chain Analytics solution using PostgreSQL, Excel, and Power BI.

The project focuses on:
- Sales Performance
- Inventory Efficiency
- Shipment Operations
- Profitability Trends
- Warehouse Performance

---

## Tools & Technologies
- PostgreSQL
- Power BI
- DAX
- Power Query
- Excel
